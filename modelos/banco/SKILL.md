# Clientes (skill de banco: só aponta para os dados)

- Lista de clientes: `~/dados/clientes.csv` (colunas: nome, email, cidade, desde)
- Compras: `~/dados/compras.csv` (cliente, data, produto, valor)
- Conversas: `~/dados/conversas/<nome>.md`

Antes de escrever para alguém, leia as três fontes desse cliente. Nunca invente compra ou data.
