# Relatório semanal (escrito para um modelo antigo)

## Como fazer

1. Primeiro, leia com atenção todo o material que eu colar.
2. Depois, separe os pedidos por cliente.
3. Organize as informações em ordem de importância.
4. Pense passo a passo antes de escrever qualquer coisa.
5. Identifique os pontos principais de cada pedido.
6. Escreva um título claro no topo do relatório.
7. Escreva um parágrafo de abertura com o resumo da semana.
8. Liste os pedidos novos em tópicos.
9. Liste os pedidos atrasados em tópicos separados.
10. Revise o texto para corrigir erros de português.
11. Verifique se nenhum pedido ficou de fora.
12. Confira se as somas estão corretas.
13. Use frases curtas e claras.
14. Use linguagem profissional.
15. Mantenha a formatação consistente do começo ao fim.
16. Em seguida, escreva uma conclusão com os próximos passos.
17. Por fim, releia tudo antes de entregar.

## Regras de formato

- Use títulos e subtítulos para organizar o texto.
- Coloque os valores em destaque.
- Seja objetivo e evite enrolação.
- Garanta que o relatório seja fácil de ler.
- Certifique-se de que a resposta esteja completa.

## O que só a loja sabe

- Os pedidos da semana estão em `pedidos/semana.csv`.
- Mande para a Marta (dona da loja), não para o caixa.
- "Pedido parado" significa sem resposta do cliente há 5 dias.
- Nunca mostre o valor que cada cliente deve; só o total.
- Cores do gráfico: verde #0E7C66 para pago, cinza #9A9AA6 para aberto.
